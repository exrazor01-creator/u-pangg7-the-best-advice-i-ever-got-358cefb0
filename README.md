# The Best Advice I Ever Got

**Entry:** "My first boss told me never to send an angry email — write it, sleep on it, and send the second draft in the morning."

**Characters:** 118 (gate: 1–200, one sentence)

## Why it fits the brief

1. **On subject:** one sentence about the best advice received, from a named giver — my first boss.
2. **Worth carrying:** specific and earned — write the angry draft, sleep on it, send the second draft in the morning; a rule that holds far beyond email, for any message sent in heat.
3. **A real voice, a real moment:** an office memory, not a slogan or fortune cookie.
4. **Tight:** every word earns its place; it reads in one breath.
5. **It lands:** the last words hand the reader a habit they can actually keep.
